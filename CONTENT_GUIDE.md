# My Inner Cat — Content Guide & Current State

> Upload this single file to Claude chat to help write new content. It explains
> what the app is, the exact formats new content must follow, the rules, and a
> full snapshot of everything that already exists (so you don't duplicate or
> unbalance it). Auto-generated by `npm run guide` — regenerate after adding content.

---

## 1. What the app is

**My Inner Cat** (myinnercat.com) is a wholesome watercolor cat personality quiz.
You answer **10 of the 27 questions** (pulled at random), get matched to one of
**20 personality archetypes**, and are then dealt **one of 89 cats** from that
archetype — revealed as a **collectible card** with a rarity tier you can share,
download, and collect. Cats range from cozy housecats to rare wild species, each
an original watercolor painting.

- **Audience:** general, ages ~10–70+. Kids enjoy the collecting + cute cats;
  adults enjoy the writing + the (true) trivia.
- **Tone:** warm, gentle, encouraging, unhurried. Never snarky, clinical, or salesy.

## 2. The voice (match this exactly)

- **Archetype description** — second person, speaks *to* the reader about who they
  are. Affirming and specific, ~3–5 sentences. E.g. "You're the friend people text
  when something hard happens. You don't panic, you don't perform…"
- **Archetype tagline** — one punchy line, sentence fragment ok. E.g. "Would rather
  be tired than bored."
- **Cat blurb** — third person, warm, ~2–4 sentences about *the cat* (its
  temperament + a charming detail) and why it fits the archetype's vibe.
- **Cat trivia** — factual and genuinely surprising or "earned." 1–2 sentences.
  Real facts only.

## 3. How content becomes the app

There are **three source markdown files**. A build script parses them into JSON,
validates everything, and optimizes the images — then the whole app (results,
gallery, share cards, sitemap, the "89 cats / 20 archetypes" copy) scales
automatically. You only ever edit the markdown + add art.

| Source file | Produces |
|---|---|
| `archetype_data.md` | the 20 archetypes |
| `cat_profiles_and_trivia.md` | the 89 cats (a cat's archetype = its `##` section) |
| `cat_quiz_scoring_tags.md` | the 27 questions + scoring tags |

## 4. Exact formats (new content must match these)

### A new archetype — in `archetype_data.md`
```md
## The Example Archetype
- **ID:** `example_archetype`
- **Tagline:** A short, punchy one-liner.

The description paragraph, second person, ~3–5 affirming sentences.

---
```
Real example:
```md
## The Cozy Giant
- **ID:** `cozy_giant`
- **Tagline:** The friend you text first when things go wrong.

You're the friend people text when something hard happens. You don't panic, you don't perform, and you don't run out of patience. Big rooms tire you out, but small circles of people you love can hold you all day. People put themselves back together faster around you, and they usually don't realize you're the reason.

---
```

### A new cat — in `cat_profiles_and_trivia.md`
Cats live under a `## Archetype Name` section header — **that header is what
assigns the cat to its archetype.** Format per cat:
```md
**Cat Name** *(rarity)*
The blurb paragraph.
*Trivia: The trivia sentence.*
```
Real example (header + one cat):
```md
## The Cozy Giant

**Ragdoll** *(common)*
Famously gentle and floppy. Ragdolls will literally go limp in your arms when you pick them up, like they trust you to handle the rest. They're indoor cats by temperament and they bond deeply to one or two people for life.
*Trivia: The breed gets its name from this go-limp behavior, which first appeared in the founding queen, Josephine, in 1960s California and has been carried in every Ragdoll line since.*
```

### A new question — in `cat_quiz_scoring_tags.md`
```md
### Q99. The question title.
*The scenario setup sentence.*

- **A.** First answer text.
  → Archetype Name, Archetype Name, Archetype Name
- **B.** Second answer text.
  → Archetype Name, Archetype Name
```
Real example:
```md
### Q1. The party arrival.
*You walk into a friend's party. Twenty people are already there and the room is loud.*

- **A.** Scan for someone you already know, post up near them, stay there.
  → Cozy Giant, Quiet Mystic, Soft-Hearted Charmer
- **B.** Find the friend who invited you, get the lay of the land, ease in.
  → Steady Companion, Old Soul, Cozy Giant
- **C.** Make a slow lap, see who looks interesting, pick a conversation.
  → Curious Explorer, Crown Bearer, Chatty Charmer
- **D.** Head straight for the snack table.
  → Sun Worshipper, Trickster, Free Spirit, Adaptive Soul, Sprint Star
```
(Archetype names in the `→` line use the display name; a leading "The" is optional —
the parser matches case-insensitively.)

## 5. Rules & conventions

- **Rarity tiers:** `common` | `uncommon` | `rare` | `legendary`. At reveal, rarer =
  less likely (weights common 40 / uncommon 30 / rare 20 / legendary 10). Make the
  most striking / elusive / wild cats the rarer tiers; everyday housecats are common.
- **Cat IDs** are derived automatically: lowercase, spaces→`_`, drop apostrophes &
  possessive "'s", strip accents. (Pallas's Cat → `pallas_cat`, Guiña → `guina`.)
- **Images:** every cat needs a watercolor painting in `images/`, named from the cat
  name: lowercase, accents stripped, apostrophes removed, spaces/hyphens → `-`, `.png`
  (e.g. "Norwegian Forest Cat" → `norwegian-forest-cat.png`). The build optimizes it
  to WebP automatically. **No image = the cat can't ship.**
- **Wild species:** if a new cat is a wild species (not a domestic breed), it must be
  added to the `WILD_SPECIES` set in `scripts/build-data.mjs` so it's labeled correctly.
- **Question tags:** each answer should tag **3–5 archetypes** (a few 2-tag answers
  exist intentionally). Tags are how matching works — every answer's tags each add a
  point; highest total wins.
- **CRITICAL — keep archetypes matchable & balanced:** a new archetype is only ever
  reachable if it's **tagged across several answers** in the questions. Add a new
  archetype and you MUST sprinkle its tag through the question pool, or no one can get
  it. Likewise, give each archetype a healthy spread of cats across rarities.
- Some archetypes are broad and naturally match more (Old Soul, Quiet Mystic); some
  are specific and should match rarely (Night Owl, Quirky Individualist). Don't force
  a perfectly flat distribution.

### The 20 archetypes
1. **The Cozy Giant** — `cozy_giant`
   _Tagline:_ The friend you text first when things go wrong.
   You're the friend people text when something hard happens. You don't panic, you don't perform, and you don't run out of patience. Big rooms tire you out, but small circles of people you love can hold you all day. People put themselves back together faster around you, and they usually don't realize you're the reason.

2. **The Sprint Star** — `sprint_star`
   _Tagline:_ Would rather be tired than bored.
   You think with your body. Sitting still in a meeting feels harder than running five miles, and if you don't move enough during the day, you sleep badly at night. You're not hyper. You just need real work for your nervous system to do. You'd rather be tired than bored.

3. **The Quiet Mystic** — `quiet_mystic`
   _Tagline:_ Watches first. Spends warmth carefully.
   You watch a room before you join it. Sometimes people read that as shy or aloof, but it isn't either. You're slow to spend your warmth, and the people who eventually get it know they earned it. You give your full attention rarely and on purpose.

4. **The Crown Bearer** — `crown_bearer`
   _Tagline:_ Doesn't need to raise a voice to be heard.
   You don't have to raise your voice to be heard. You take your time answering questions, you don't waste words, and you've never been comfortable performing for attention you didn't ask for. People mistake your calm for stoicism. It's actually self-trust.

5. **The Curious Explorer** — `curious_explorer`
   _Tagline:_ Allergic to boredom. Loyal to surprise.
   You've changed routes home from work just to see a different street. New restaurants, new cities, hobbies you'll abandon in a year. You'd rather try something and learn it wasn't for you than wonder. The list of things you've been into and moved on from is long, and you don't regret a single one.

6. **The Soft-Hearted Charmer** — `soft_hearted_charmer`
   _Tagline:_ Remembers every birthday. Forgives most things.
   You remember everyone's birthday. Not because you're trying to, but because little details about the people you love stick to you the same way song lyrics do. You can hold a grudge if pushed, but you'd really rather not, and forgiving people usually feels like a relief. People feel safe around you. They're not wrong to.

7. **The Chatty Charmer** — `chatty_charmer`
   _Tagline:_ Has opinions. Shares them. Lives loud.
   You have opinions and you share them. Long phone calls, dinner table monologues, voice memos that ran longer than the conversation that prompted them. This is just how your brain processes the world. Quiet people sometimes find you exhausting, and you can live with that. The people who get you don't want anyone else.

8. **The Steady Companion** — `steady_companion`
   _Tagline:_ Shows up. Does the thing. Doesn't make a thing of it.
   You're who people call when they need a ride to the airport. Not flashy, not loud, not particularly mysterious. You're also not interested in being any of those things. You show up, you do what you said you'd do, and you make other people's lives easier without making a thing of it. The world runs on people like you.

9. **The Trickster** — `trickster`
   _Tagline:_ Sees the loophole. Found the secret level.
   You see the loophole. You found the secret level. You're the one who got everyone laughing in a meeting they were dreading, and also the one who took apart the household smoke detector because you wanted to know how it worked. People underestimate how smart you are because you'd rather be funny than impressive.

10. **The Hidden One** — `hidden_one`
   _Tagline:_ Inner life: rich. Outer life: theirs.
   You're a private person and you've stopped feeling weird about it. Your inner life is rich and most of it stays inner. You like nature, long walks alone, and books you don't talk about with anyone. The few people who know the real you are inside a circle most people never enter.

11. **The Adaptive Soul** — `adaptive_soul`
   _Tagline:_ Doesn't fit one mold. Stopped trying to.
   You find your footing in unexpected places. Other people would call your hobbies, jobs, and friend groups eclectic. You'd call them honest. You don't fit one mold, and trying to over the years just made you tired. Now you do what works for you, and you're more interesting for it.

12. **The Quirky Individualist** — `quirky_individualist`
   _Tagline:_ Recognizable from across a room.
   You've never been able to suppress what makes you weird, and at some point you stopped trying. Your fashion sense is yours alone. Your taste in music makes playlists hard. Your laugh is recognizable from across a room. People remember you because there's no one to confuse you with.

13. **The Sun Worshipper** — `sun_worshipper`
   _Tagline:_ Finds the warmest patch within thirty seconds.
   You find the warmest patch in any room within thirty seconds of arriving. Good food, good naps, sun through a window in winter, the right blanket on the right couch. These are not small things to you. People who don't slow down probably miss most of what's worth being alive for, and you decided a while ago not to be one of them.

14. **The Loyal Guardian** — `loyal_guardian`
   _Tagline:_ Goes to war for the people they love. Doesn't need to be asked.
   You will go to war for the people you love and you do not need them to ask. You watch carefully, you judge intent carefully, and you remember who was kind to your people and who wasn't. People sometimes mistake your reserve for coldness. It isn't. You're sizing them up, and you make up your mind once.

15. **The Dreamer** — `dreamer`
   _Tagline:_ Spends part of every day somewhere no one else can see.
   You spend a lot of your day in places no one else can see. You write things in your head that don't quite make it to paper. You notice the way light hits a building, the unsaid thing in a conversation, the song playing under everything else. The people who love you have learned not to interrupt the staring-out-the-window phases. That's where your best work happens.

16. **The Old Soul** — `old_soul`
   _Tagline:_ Slow to answer. Worth waiting for.
   You've been quiet at parties since you were ten. Friends bring you their hardest questions because you don't rush to answer them and you don't pretend to know things you don't. You like long conversations, slow mornings, and the kind of books that take a year to finish. You're rarely in a hurry. People who spend time around you tend to slow down too.

17. **The Joyful Optimist** — `joyful_optimist`
   _Tagline:_ Not naive. Just choosing well.
   You're not naive. You decided a while back that you'd rather find the bright thread in a thing than the dark one. People are surprised by how much of life genuinely makes you happy. Small dogs, weird clouds, songs that hit right, friends who answer the phone. Your good mood is the kind that catches, and it doesn't take a lot to maintain.

18. **The Night Owl** — `night_owl`
   _Tagline:_ Mornings happen. Evenings are theirs.
   The world makes more sense to you after dark. You do your best thinking past 11 p.m. Your friends know not to text you before noon unless something is on fire. You like quiet streets, lamplight, the way music sounds louder in headphones at night. Mornings happen to you. Evenings are yours.

19. **The Free Spirit** — `free_spirit`
   _Tagline:_ Travels light. Wants less. Has more.
   You travel light. Not just literally. Your needs are simple, and your contentment doesn't depend on much. You don't have to be in a relationship, you don't have to live in the right city, you don't have to be doing the impressive thing. The freedom you have is the freedom you built by wanting less than other people want. It looks like luck. It isn't.

20. **The Romantic** — `romantic`
   _Tagline:_ Loves hard. Doesn't dilute it.
   You love hard and you don't dilute it. The people you've loved have always known they were loved. You remember anniversaries, you write the long card, you cry at the good moments because the good moments deserve it. Some people find this overwhelming. Other people would never want to be loved any other way.

- **Q21. The favorite season** — Which one is genuinely yours?

## 7. Expanding — balance checklist

When adding content, keep these in mind:
- **New archetype** → write its entry, then **tag it into ~6–10 answers** across the
  question pool, and give it **4–5 cats** spread across rarities (incl. ≥1 common so
  it's reachable, and ideally a legendary for the chase).
- **New cat** → pick the archetype whose vibe it fits; choose a rarity that keeps that
  archetype's spread sensible; write blurb + trivia in voice; add the painting.
- **New question** → a fresh everyday scenario (don't repeat existing themes — see the
  list above); 3–4 answers; each answer tags 3–5 archetypes that the choice implies.
- After editing: `npm run data` (validates + optimizes), then `npm run build`,
  commit, push. Re-run `npm run guide` to refresh this file.

## 8. How to ask Claude chat for content

Paste this guide, then ask for what you want and request paste-ready output, e.g.:

> "Using the formats and voice in this guide, write **3 new archetypes** (with ids,
> taglines, descriptions), **4 cats each** (names, rarities, blurbs, trivia, and the
> image filename I'll need), and **6 new questions** that tag toward them. Avoid
> duplicating any existing archetype, cat, or question theme. Output each in the exact
> markdown format for its source file, ready to paste."

Ask it to also list the **image filenames** you'll need to create for any new cats.
