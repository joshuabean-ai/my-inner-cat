# My Inner Cat

A watercolor personality quiz (Next.js 15 / App Router, React 19, TypeScript, Tailwind v3).
Answer 10 of 27 random questions → matched to 1 of 89 cats across 20 archetypes, revealed as a
collectible card with a rarity tier you can share, download, and collect.

**Live:** https://myinnercat.com (Vercel). No backend, no DB — content is static JSON; result
state lives in the URL; the "collection" lives in the visitor's localStorage.

See `my_inner_cat_build_spec.md` for the original design; this file is the current state.

## Commands

- `npm run dev` — local dev server
- `npm run data` — regenerate `data/*.json` + optimized images from the source markdown
- `npm run guide` — regenerate `CONTENT_GUIDE.md` (self-contained brief for authoring content)
- `npm run build` — production build (prerenders results, gallery, OG + share cards)
- `npm run test` — Vitest unit tests for the matching engine
- `npm run start` — serve the production build
- **Never run `dev` and `build`/`start` at the same time** — they share `.next` and corrupt it.

## Routes

- `/` — homepage (hero, card fan, Begin + Browse/About links)
- `/quiz` — the quiz (client `QuizFlow`; randomness is client-side to avoid hydration mismatch)
- `/result/[archetype]/[cat]` — result card; prerendered for all 89 pairs (`generateStaticParams`)
- `/cats` — the gallery: all 89, filter by rarity/archetype/collection status
- `/about` — story + how-it-works
- `/api/card/[archetype]/[cat]` — downloadable/shareable portrait card PNG (next/og + sharp)
- `opengraph-image` per result — link-preview card (shares `lib/og-card.tsx`)
- `robots.ts`, `sitemap.ts`, `manifest.ts`, `icon.svg`/`apple-icon.png`

## Architecture

- `data/*.json` — all content. GENERATED (see below) — edit the markdown, not the JSON.
- `lib/matching.ts` — `matchArchetype()` (tag tally + 3-tag-narrow tiebreak) + `selectVariant()`
  (rarity-weighted). Pure, RNG-injectable, unit-tested.
- `lib/rarity.ts` — tier metadata (colors, foil, `RARITY_WEIGHTS`) + `drawOdds()`.
- `lib/selection.ts` — `selectQuestions()` (Fisher-Yates, RNG-injectable).
- `lib/data.ts` — typed loaders + `toSlug`/`fromSlug` (id `cozy_giant` ↔ slug `cozy-giant`).
- `lib/collection.ts` — localStorage collection. A cat is collected by DRAWING it in the quiz
  (`flagPull` on completion → `RecordPull` on the result page), not by browsing.
- `lib/og-card.tsx` — renders the share card (1080×1350) and OG (1200×630); fonts in `assets/fonts/`.
- `lib/site.ts` — `SITE_URL` from `NEXT_PUBLIC_SITE_URL` (default `https://myinnercat.com`).
- Nav: `Masthead` (Quiz/Cats/About, active state) is the nav; `Footer` is a brand sign-off only.

## Conventions

- Palette + fonts (Fraunces display / Geist body) in `tailwind.config.ts` and `app/globals.css`.
- Images: `public/cats/{archetype-slug}-{cat-slug}-{rarity}.webp` — `cat.image` must match exactly.
- All animation respects `prefers-reduced-motion` (global rule in `globals.css`).
- `body { overflow-x: clip }` guards against mobile horizontal overflow.
- Analytics via `@vercel/analytics` `track()`: `quiz_started`, `quiz_completed` (with `archetype`),
  `result_shared`, `quiz_retaken`.

## Regenerating data from source content

`data/*.json` is generated by `scripts/build-data.mjs` (`npm run data`):
- `archetype_data.md` → `archetypes.json` (20) + naming conventions
- `cat_profiles_and_trivia.md` → `cats.json` (89) — archetype from the `##` section header
- `cat_quiz_scoring_tags.md` → `questions.json` (27)

It validates referential integrity, sets each cat's `origin`/`number`, and optimizes each
illustration from `images/` (the untouched ~2.5 MB originals, gitignored) into `public/cats/` as a
1024px WebP (~120 KB). Two source images have typo'd names handled by `SOURCE_OVERRIDES`
(`main-coone.png` → Maine Coon, `lapirm.png` → LaPerm).

Content note: answers `q11c`, `q15a`, `q27c` intentionally have only 2 tags (engine handles it).

## Deploy

GitHub `joshuabean-ai/my-inner-cat` → Vercel, **auto-deploys on push to `main`**. Workflow: commit,
`git push`, then verify with `gh api repos/joshuabean-ai/my-inner-cat/commits/main/status --jq .state`.
Env: `NEXT_PUBLIC_SITE_URL=https://myinnercat.com` (set in Vercel). Primary domain is the apex
(`myinnercat.com`, serves 200; `www` redirects to it). `gh` is authenticated; `vercel` CLI is
installed but not logged in (not needed for deploys). Lighthouse: 99 / 100 / 100 / 100.

## Testing UI on mobile

`chrome --headless --window-size=375` does NOT emulate mobile (it crops a wider layout → false
overflow). Use CDP `Emulation.setDeviceMetricsOverride({width,height,mobile:true})` via
`chrome-remote-interface` against `chrome --remote-debugging-port=9222`; run the script from the
repo root so it resolves node_modules.
