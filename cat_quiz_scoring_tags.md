# Cat Personality Quiz — Scoring Tag Reference

Complete answer-to-archetype mapping for the matching engine. Each answer is tagged with the 3–5 archetypes it scores toward when selected.

---

## Methodology

When a user takes the quiz, the system randomly pulls **10 questions** from this pool of 27. For each answered question, every tag on the chosen answer adds 1 point to the corresponding archetype's score. After all 10 questions, the highest-scoring archetype is the user's match. Ties are broken by the user's most narrowly-tagged answer (a 3-tag answer is a stronger signal than a 5-tag answer).

Once an archetype is matched, the system then weighted-randomly selects one cat from that archetype's variant pool (common 40% / uncommon 30% / rare 20% / legendary 10%) and that cat becomes the reveal.

## Notes for Playtesting

After roughly 50–100 real plays, pull the actual archetype distribution from your analytics and look for these patterns:

- **Dominance**: One archetype claiming more than 25–30% of all results. Usually means too many answers tag it. Trim tags from answers where the fit is weakest.
- **Starvation**: An archetype matched less than 2–3% of the time. Add tags to answers where it plausibly fits but wasn't included.
- **Misfit reports**: If your daughter or a friend takes the quiz and the result feels wrong, look at their answer pattern and re-tag the answers that produced the wrong winner.

Don't try to make the distribution perfectly flat. Some archetypes (Old Soul, Quiet Mystic) are broad personality types that naturally land more often. Others (Night Owl, Quirky Individualist) are specific and should be rarer matches that feel earned when they do hit.

## Sample JSON Schema for Build

For the dev phase, a clean way to structure this in code:

```json
{
  "questions": [
    {
      "id": "q1",
      "title": "The party arrival",
      "setup": "You walk into a friend's party. Twenty people are already there and the room is loud.",
      "answers": [
        {
          "id": "q1a",
          "text": "Scan for someone you already know, post up near them, stay there.",
          "tags": ["cozy_giant", "quiet_mystic", "soft_hearted_charmer"]
        },
        {
          "id": "q1b",
          "text": "Find the friend who invited you, get the lay of the land, ease in.",
          "tags": ["steady_companion", "old_soul", "cozy_giant"]
        }
      ]
    }
  ],
  "archetypes": [
    {
      "id": "cozy_giant",
      "name": "The Cozy Giant",
      "description": "You're the friend people text when something hard happens...",
      "variants": [
        {"name": "Ragdoll", "rarity": "common"},
        {"name": "Maine Coon", "rarity": "common"},
        {"name": "Norwegian Forest Cat", "rarity": "uncommon"},
        {"name": "Siberian", "rarity": "rare"}
      ]
    }
  ]
}
```

The matching engine just iterates through the user's chosen answers, tallies the `tags`, and returns the highest score. Then it weighted-randomly picks a variant from the matched archetype's `variants` list using the rarity weights (common 40 / uncommon 30 / rare 20 / legendary 10).
